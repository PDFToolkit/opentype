# Documents de référence conservés

[English](README.md) | Français

`OTGuide.pdf` est le guide Adobe OpenType User Guide for Adobe Fonts, daté
d'octobre 2008. Le nom et les octets fournis sont conservés. Ses 13 pages
physiques expliquent les fonctionnalités des applications ; le tableau de la
page 13 comprend `liga`, `smcp`, `salt` et d'autres tags. C'est un guide
d'utilisation plutôt qu'une spécification binaire.

`metadata.json` conserve sa taille et son SHA-256. Le guide conserve ses mentions
Adobe et est exclu des archives Composer. Les définitions techniques utilisent
[OpenType 1.9.1](https://learn.microsoft.com/en-us/typography/opentype/spec/).

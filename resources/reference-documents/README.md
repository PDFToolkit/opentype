# Preserved reference documents

English | [Français](README.fr.md)

`OTGuide.pdf` is Adobe's OpenType User Guide for Adobe Fonts, dated October
2008. The supplied filename and bytes are preserved. Its 13 physical pages
explain application features; the table on page 13 includes `liga`, `smcp`,
`salt` and other tags. It is a usage guide rather than a binary specification.

`metadata.json` records its byte count and SHA-256. The guide retains its Adobe
notices and is excluded from Composer archives. Technical definitions use
[OpenType 1.9.1](https://learn.microsoft.com/en-us/typography/opentype/spec/).
